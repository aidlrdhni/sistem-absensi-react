# 📍 Sistem Absensi Digital Berbasis Selfie & GPS Geofencing

Aplikasi web presensi digital modern yang dibangun menggunakan **React.js**, **Tailwind CSS**, dan **Supabase**. Dilengkapi dengan verifikasi foto selfie secara langsung melalui kamera browser (*WebRTC*), deteksi koordinat lokasi GPS *real-time* dengan validasi radius jarak (*Geofencing*), serta penyimpanan data dan foto terpusat di *cloud*.

---

## ✨ Fitur Utama

- **Jam & Tanggal Real-Time:** Penunjuk waktu akurat yang diperbarui setiap detik.
- **Verifikasi Foto Selfie (HTML5 Canvas & MediaDevices API):** Mengambil foto wajah langsung dari kamera perangkat dan mengunggahnya otomatis ke *Cloud Storage*.
- **GPS Geofencing (Algoritma Haversine):** Menghitung jarak lokasi pengguna secara presisi terhadap titik lokasi kantor/instansi (radius maksimal **500 meter** dari SMKN 2 Banjarmasin).
- **Mode Kehadiran Dinamis:**
  - **Hadir:** Mewajibkan foto selfie dan validasi GPS dalam radius lokasi.
  - **Izin / Sakit:** Menyembunyikan kamera & GPS secara otomatis, diganti dengan kolom keterangan alasan.
- **Pop-up Notifikasi Interaktif:** Umpan balik visual instan (*Diterima* / *Ditolak*) lengkap dengan detail jarak lokasi dan waktu presensi.
- **Live Cloud Database & Storage:** Seluruh riwayat kehadiran, tautan titik lokasi Google Maps, dan foto selfie tersimpan secara *real-time* di **Supabase**.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Styling & UI:** Tailwind CSS, Lucide React (Icons)
- **Backend & Database:** Supabase (PostgreSQL Database & Cloud Storage)
- **Browser APIs:** `navigator.mediaDevices` (Kamera), `navigator.geolocation` (GPS)

## 🚀 Cara Menjalankan di Lokal

1. **Clone repository ini:**
   ```bash
   git clone [https://github.com/aidlrdhni/sistem-absensi-react.git](https://github.com/aidlrdhni/sistem-absensi-react.git)
   cd sistem-absensi-react
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Konfigurasi Environment Variables:**
   Buat file `.env` di direktori utama project, lalu isi kredensial project Supabase:
   ```env
   VITE_SUPABASE_URL=[https://your-project-id.supabase.co](https://your-project-id.supabase.co)
   VITE_SUPABASE_ANON_KEY=your-supabase-publishable-key
   ```

4. **Jalankan server development:**
   ```bash
   npm run dev
   ```

## 🗄️ Struktur Tabel Database (Supabase)

Jalankan kueri SQL berikut pada **SQL Editor** Supabase untuk menyiapkan tabel `absensi`:

```sql
create table public.absensi (
  id bigint generated by default as identity primary key,
  nama text not null,
  divisi text not null,
  status text not null,
  keterangan text,
  foto_url text,
  lat text,
  lng text,
  jarak integer,
  tanggal text not null,
  jam text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```
